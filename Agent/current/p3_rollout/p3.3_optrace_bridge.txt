WHAT CHANGED (new script, measurement-side only)
  - scripts/htp_optrace_bridge.py (NEW): reads chrometrace_qnn_htp_analysis_summary.json and maps
    to the §4 canonical fields (PCYCLE, no conversion):
       wall (Q4 graph-wall)     = htp_overall_summary.timeline_cycles  (= max(end)-min(start))
       cbusy (Q2 cycles_used)   = HMX unit cycles_used (MAC occupancy)
       bottleneck-busy (Q2)     = max-over-units cycles_used + the saturated unit name (= domain)
       num_dominant (Q1)        = Σ dp_cycles over dominant_path_htp_0 (critical path)
       us                       = graph_execute_us (clock self-check)
    --table mode mixes optrace impls (--add label:dir:N) AND gdnbm spec.json (--add-gdnbm, the P3.2
    canonical JSON) into ONE PCYCLE table; cross-impl number = graph-wall÷N (§2 Q4 +
    feedback_cross_impl_compare_graphwall_only). Handles both overall-summary shapes (dict / list-of-1).
